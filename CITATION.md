# Citing OpenMeasure

## Citing the software

If you use OpenMeasure in a publication, report, or project, please cite the software. GitHub generates a formatted citation automatically from `CITATION.cff` (see **"Cite this repository"** on the repository page).

**APA**

> McCray, V. (2026). *OpenMeasure: An open-source validation toolkit for research data, measures, models, and programs* (Version 0.1.0) [Computer software]. https://github.com/victoriamccray/openmeasure

**BibTeX**

```bibtex
@software{mccray_openmeasure_2026,
  author  = {McCray, Victoria},
  title   = {OpenMeasure: An Open-Source Validation Toolkit for Research Data, Measures, Models, and Programs},
  year    = {2026},
  version = {0.1.0},
  url     = {https://github.com/victoriamccray/openmeasure}
}
```

## Citing the methods

OpenMeasure implements established statistical methods and does not introduce new statistical methodology. If you are citing a method (e.g., Cronbach's alpha or the Spearman-Brown correction), please cite the original methodological literature in addition to OpenMeasure where appropriate.

Examples include:

- Cronbach, L. J. (1951). *Coefficient alpha and the internal structure of tests*. *Psychometrika, 16*(3), 297–334.
- Brown, W. (1910). *Some experimental results in the correlation of mental abilities*. *British Journal of Psychology, 3*(3), 296–322.

Additional references are provided within each module's documentation.

## Responsible use

OpenMeasure is designed to support research validation and transparent reporting. Results should be interpreted alongside their assumptions, limitations, and the broader study context. Individual statistics should not be used in isolation to make high-impact decisions.
